# PrepSlay.io - High-Level Design Document

## 🎯 Project Overview

**PrepSlay.io** is a modern SaaS platform that automates the interview process using AI voice technology. It allows recruiters to create AI-conducted interviews that candidates can complete remotely, with automatic scoring and feedback generation.

## 🏗️ High-Level Architecture

### Frontend Layer
- **Landing Page**: Marketing site with features, pricing, and sign-up
- **Authentication**: Google OAuth integration via Supabase
- **Dashboard**: Main application interface for recruiters
- **Interview Creation**: Multi-step wizard for creating AI interviews
- **Interview Management**: View and manage created interviews
- **Analytics & Reports**: Candidate performance analysis
- **Billing**: Credit-based payment system

### API Layer
- **AI Model API**: Question generation using OpenRouter/Gemini
- **AI Feedback API**: Post-interview analysis and scoring
- **Voice API**: Integration with PlayHT for voice synthesis
- **Payment API**: PayPal integration for credit purchases

### Database Layer (Supabase)
- **Users Table**: User profiles, authentication, and credits
- **Interviews Table**: Interview configurations and metadata
- **Feedback Table**: Candidate responses and AI-generated feedback

### Voice AI Layer (VAPI Platform)
- **Speech Recognition**: Deepgram Nova-2 for real-time transcription
- **Voice Synthesis**: PlayHT for AI voice generation
- **Conversation Management**: Real-time interview orchestration

## 🛠️ Technology Stack

### Frontend Framework
- **Next.js 15.2.4** with App Router
- **React 19** with server-side rendering
- **TypeScript/JavaScript** (mixed codebase)
- **Tailwind CSS 4** for styling

### Database & Backend
- **Supabase** for database, authentication, and real-time features
- **PostgreSQL** (via Supabase)

### AI & Voice Integration
- **VAPI** - Voice AI platform for real-time conversations
- **OpenRouter** - AI model routing (using Gemini Flash 1.5)
- **Deepgram Nova-2** - Speech-to-text transcription
- **PlayHT Jennifer** - Text-to-speech synthesis

### Payment & Billing
- **PayPal** integration for credit purchases
- Credit-based pricing model

## 📊 Database Schema

### Users Table
```sql
- id (primary key)
- name (from Google OAuth)
- email (unique identifier)
- picture (profile image URL)
- credits (interview credits remaining)
- created_at
- updated_at
```

### Interviews Table
```sql
- id (primary key)
- interview_id (UUID, shareable identifier)
- userEmail (foreign key to Users)
- jobPosition
- jobDescription
- duration
- type (JSON array of interview types)
- questionList (JSON array of AI-generated questions)
- created_at
```

### interview-feedback Table
```sql
- id (primary key)
- interview_id (foreign key)
- userName (candidate name)
- userEmail (candidate email)
- feedback (JSON object with ratings and analysis)
- recommended (boolean)
- created_at
```

## 🔄 Core User Flows

### 1. Recruiter Flow
1. **Authentication**: Google OAuth sign-in
2. **Interview Creation**: 
   - Enter job details (position, description, duration, type)
   - AI generates tailored questions using Gemini
   - Creates shareable interview link
3. **Interview Management**: View all interviews, candidate responses
4. **Analytics**: Review AI-generated feedback and ratings

### 2. Candidate Flow
1. **Access Interview**: Click shared link
2. **Registration**: Enter name and email
3. **Voice Interview**: Real-time AI conversation via VAPI
4. **Completion**: Automatic feedback generation and storage

### 3. Billing Flow
- Credit-based system (20, 50, 120 credits packages)
- PayPal integration for payments
- 1 credit = 1 interview creation

## 🧠 AI Integration Architecture

### Question Generation
- Uses **OpenRouter + Gemini Flash 1.5**
- Structured prompts with job details
- Returns JSON-formatted questions categorized by type

### Voice Interview Engine
- **VAPI Platform** orchestrates the entire voice conversation
- **Deepgram Nova-2** for speech recognition
- **PlayHT Jennifer voice** for speech synthesis
- **GPT-4** for conversation intelligence and responses

### Feedback Analysis
- Post-interview conversation analysis
- AI generates structured feedback with ratings
- Categories: Technical Skills, Communication, Problem Solving, Experience
- Boolean recommendation with explanatory message

## 🎤 Deepgram Integration Details

### Purpose
Deepgram is used as the **speech-to-text (STT) transcription service** in the voice AI interview system.

### Configuration
```javascript
transcriber: {
    provider: "deepgram",
    model: "nova-2",
    language: "en-US",
}
```

### Functionality
1. **Real-time Speech Recognition**: Converts candidate's spoken responses into text
2. **Interview Flow Integration**: Transcribed text is sent to GPT-4 for analysis
3. **VAPI Platform Integration**: Coordinates with PlayHT and OpenAI for complete voice pipeline

### Voice Pipeline
```
Candidate Speaks → Deepgram Nova-2 → Text → GPT-4 → Response → PlayHT → AI Voice
```

### Benefits
- **Interview-Specific Optimization**: Nova-2 trained on conversational speech
- **Technical Term Recognition**: Better understanding of job-specific terminology
- **Real-time Performance**: Low latency for natural conversation flow
- **Accent Flexibility**: Handles various accents and speaking styles
- **Reliability**: Enterprise-grade service for professional contexts
